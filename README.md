# PHP Bartenders - Website Institucional

## 1. Nome e objetivo do projeto

**Nome:** Desenvolvimento de Website Institucional para PHP Bartenders.

**Objetivo:**
Desenvolver um website institucional para a empresa PHP Bartenders, 
com o objetivo de ampliar sua presença digital, divulgar seus serviços 
de bar para eventos, apresentar seus trabalhos e facilitar o contato 
com potenciais clientes, contribuindo para a captação de novos eventos.

## 3. Tecnologias utilizadas

- HTML: Estruturação das páginas do site.
- CSS: Estilização, layout e responsividade.
- Visual Studio Code: Ambiente de desenvolvimento.
- Git e GitHub: Controle de versão e colaboração entre integrantes.

## 4. Instalação e execução

Para executar o projeto localmente:

1. Clone o repositório do GitHub.
2. Abra a pasta do projeto no Visual Studio Code.
3. Instale a extensão Live Server.
4. Abra o arquivo index.html.
5. Clique com o botão direito e selecione "Open with Live Server".

O site será aberto automaticamente no navegador.

## 5. Principais funcionalidades

- Página inicial com apresentação da empresa.
- Apresentação dos serviços oferecidos.
- Galeria de fotos de eventos realizados.
- Página institucional sobre a PHP Bartenders.
- Página de contato com informações para atendimento.
- Botões de acesso às redes sociais e WhatsApp.
- Formulário visual para solicitação de orçamento.

## 6. Requisitos e dependências

- Navegador atualizado (Google Chrome, Firefox ou Edge).
- Visual Studio Code.
- Extensão Live Server (opcional, para facilitar a execução).
- Git (para clonar e atualizar o repositório).

Não são necessárias dependências adicionais.
